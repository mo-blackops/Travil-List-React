# 🌴 Far Away — Travel Packing List 💼

A clean, interactive travel checklist built with **React** to help you organize, sort, and track your packing items before any trip.

## ✨ Features

- **Add Items:** Select item quantities and add custom packing items to your list.
- **Track Packing Progress:** Toggle items as packed/unpacked with a live strikethrough indicator.
- **Delete & Clear:** Remove individual items or clear the entire packing list in one click.
- **Smart Sorting:** Sort items by input order, alphabetically by description, or by packed status.
- **Real-Time Statistics:** Dynamic footer displaying total items, packed count, and completion percentage.

## 🛠️ Tech Stack

- **React** (`useState` for state management & derived state)
- **JavaScript (ES6+)**
- **CSS3**
